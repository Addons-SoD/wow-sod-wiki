# 魔兽世界 · 探索赛季 Wiki

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-%E5%9C%A8%E7%BA%BF%E6%B5%8F%E8%A7%88-2ea44f)](https://addons-sod.github.io/wow-sod-wiki/)

《魔兽世界》怀旧服 **探索赛季（Season of Discovery，SoD）** 的玩家资料 Wiki，
内容以简体中文编写，页面通过 GitHub Pages 静态托管。

## 站点地址

- Pages 站点：<https://addons-sod.github.io/wow-sod-wiki/>
- 仓库：<https://github.com/Addons-SoD/wow-sod-wiki>

## 内容规划

- [ ] 职业指南：符文解锁路线、Build 与手法
- [ ] 副本攻略：团队副本与五人本 Boss 机制
- [ ] 事件与活动：梦魇入侵等世界事件时间线
- [ ] 装备数据库：阶段 Bis 与获取途径
- [ ] 更新日志：官方蓝贴要点

## 本地开发

仓库是纯静态页面，无需构建：

```bash
git clone https://github.com/Addons-SoD/wow-sod-wiki.git
# 直接打开 index.html 即可预览
```
